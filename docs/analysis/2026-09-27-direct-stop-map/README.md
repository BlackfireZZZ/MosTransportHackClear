# Прямой остановочный прогноз и факторы на карте

Режим **Планирование → Остановочная модель · прямой прогноз** отдаёт собственные
прогнозы `direct-stop-calendar-history.v1:calendar_weekday_blend` по остановке,
направлению, дате и часу. Суммы не нормируются на конкурсную маршрутную модель.
Выбранная остановочная модель — календарная смесь, а не отклонённый CatBoost.
Прошлый режим «Опубликованный маршрутный прогноз» сохраняет прежний контракт.

Карта показывает посадки, а не процент заполнения салона. Цветовые диапазоны
фиксированы: 0 — серый, (0,10) — синий, [10,50) — охра, 50+ — красный. Единица
шкалы — средние посадки в час интервала; месячный и годовой агрегат делится на
число часов в соответствующем календарном интервале. Это визуальные диапазоны,
не границы вместимости. Размеры точек относительны внутри выбранного интервала.
Числа доступны в таблице и CSV; цвет не является единственным носителем смысла.

При первом открытии выбирается первый интервал с положительным прогнозом для
известной остановки; выбранные пользователем интервалы, включая нулевые,
сохраняются. Нет координат — нет маркера, но строка остаётся в таблице. Клик
использует исходный GTFS stop/direction, без неявного соответствия OSM.

Факторы погоды, календаря, событий и трафика включаются отдельно и умножают
прямые прогнозы на заданные пользователем коэффициенты. При выключении
коэффициент равен 1. Календарные признаки обученной остановочной модели при этом
не удаляются. Обученные внешние ветки доступны только в другом режиме,
«Эксперимент с внешними источниками»; остановочных ablation-моделей этих
источников нет. Такой переключатель нельзя выдавать за новую обученную модель.

Источник: 854976 численных прогнозов v3 за ноябрь–декабрь 2025, SHA256
`5955868aee38626c723e390644462da757bb1fdf3cf50354f21215b0551ef4cb`.
Прямой артефакт хранит float-значения без округления; месяц суммирует исходные
часы. Год за пределами декабря повторяет средний профиль каждой остановки
и остаётся качественной проекцией. Остановки/направления выведены косвенно,
не являются измеренными метками; неизвестная прогнозная масса составляет
72.21123% полного источника. Интервалы неопределённости не оценены.

[Контракт и воспроизведение артефакта](../../../data/planning/STOP_MODEL.md).
[MapLibre circle-color](https://maplibre.org/maplibre-style-spec/layers/#circle-color)
поддерживает цвет из GeoJSON-свойства: опциональное свойство сохранит прежнюю
окраску для других потребителей карты. Новых библиотек/зависимостей нет.
