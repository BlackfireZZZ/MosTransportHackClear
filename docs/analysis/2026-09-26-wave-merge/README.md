# Объединение повторных начал одной волны

TASK-068. Дополнение к сравнению расписания на трёх реальных окнах 15 мая2025.

Проверяемое изменение: несколько кандидатов внутри одного адаптивного временного
окна объединяются в одну альтернативную волну; разные адаптивные окна и выраженная
пауза защищают близкие раздельные волны. Нет фиксированного запрета остановок через
Nсекунд. Исходные оплаты и все исходные начала сохраняются. Метод не доказывает,
что объединённая группа соответствует одной физической остановке.

## Правило

Используются уже откалиброванные на январе–апреле окна адаптивного детектора из
TASK067: ширины2/3/5/10/20/40/80секунд, выбранные по избытку над локальным фоном,
без переобучения. Объединяются только кандидаты в одном полуоткрытом непересекающемся
окне. Первый кандидат становится представителем; остальные остаются в members.
За пределами адаптивных окон ничего не объединяется. Группы не пересекают окна.

Дополнительное veto: берутся полные промежутки без событий, пересекающие открытый
интервал между кандидатами. rate = число оплат в опорном окне / число занятых
секунд. score = min(1, количество межсобытийных промежутков × exp(-rate×max_gap)).
При score<0.01 кандидаты остаются раздельными. Это **эвристический score**, не
калиброванная вероятность: rate оценён условно на активности, оплаты не обязаны
быть стационарным пуассоновским процессом. Источник формы survival-функции:
[NIST exponential distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3667.htm).
Само правило объединения является нашей проверяемой гипотезой, не методом NIST.

Отсутствие обнаруженной паузы не доказывает отсутствие второй посадки. Две реальные
близкие остановки без различимого разрыва могут быть объединены ошибочно. Поэтому
результат хранится как вариант с исходными members, а визуализация переключается
между исходными и объединёнными метками. Нельзя объявлять такую группу достоверной
остановкой или использовать её в hard-label обучении без дальнейшей валидации.

## Сравнение с интервалами расписания

Для исходных и объединённых начал заново подобраны последовательности с1–6
перегонами между событиями, масштабом1.0, штрафом15секунд за пропущенную позицию.
Рассчитаны9контролей с перестановкой длительностей. Красные метки маршрута17 после
объединения: MAE14.6секунды, контроль16.6,24почтиравныхначальныхпозиции. Хорошая
подгонка всё ещё не означает уникальной привязки к остановкам.

Визуализация показывает реальные30секундные количества по всем устройствам,
красные наблюдаемые начала, синий пунктир ожидаемых начал и оранжевый пунктир
там, где путь содержит геометрическую оценку. По умолчанию ожидание для каждого
перехода отсчитывается от предыдущего наблюдаемого начала; отдельный режим
показывает непрерывную цепочку от первого начала. Это интервалы прокси-расписаний,
не расписание подтверждённого исторического рейса. Таблица сравнивает локальные
интервалы независимо от выбранного режима размещения линий.
