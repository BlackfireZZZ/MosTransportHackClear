## Критерии до реализации новых функций

|Пункт|Найденное состояние|Что необходимо для зачёта|
|---|---|---|
|Календарь|Включён, ранее измерен положительный эффект|Показать ссылку и одинаковые окна ablation|
|Погода|Полная выгрузка, предыдущая ablation ухудшает score|Честно показать эффект; проверить past-only признаки|
|События/новости|KudaGo ретроспективный, историческая доступность не доказана|Исторически датированные факторы и проверка эффекта|
|Трафик|Найдены датированные сводки DtOperativno|Выгрузка, покрытие, ограничение по дате доступности и ablation|
|Область применения|10 маршрутов, январь–октябрь — история, 61 день — сдача|Сводная таблица ограничений и переносимости|
|Коэффициенты|UI был отключён|Ручные поправки на выбранный срез сразу меняют результат|
|Агрегация/приём|Проверяемые метки, сетка, хеши, публикация|Повторные проверки объединённого кода прошли|
|Архитектура/производительность|API/Docker работают, замеров не было|Опубликовать реальные latency/RPS с условиями|
|День/месяц/год|Реальные день/месяц, год демонстрационный|Явно ограниченный годовой сценарий|
|Остановка/направление/карта|Контракт API есть, конкурсный запуск без остановочных рядов|Оценочный слой с сохранением неизвестной массы|
|CSV|Работает для выбранного snapshot|Расширить на новый сценарный результат|
|Бизнес-применимость|Пики посадок; нет данных о наполнении|Показать решения по спросу, не выдумывать вместимость|

Привязано 35,30% исторических валидаций, Q1 — только 1,0707%; это покрытие,
не точность. Направление и остановка конкретного движущегося трамвая не
наблюдаются: API может передавать оценку, но текущая позиция требует телеметрии.
Остановочная модель сама по себе не закрывает внешние источники и SLA.
Четыре полных балла нельзя обещать без подтверждённого эффекта четырёх категорий.


## Реализовано и проверено после аудита

В интерфейсе раздел **Планирование**: выберите маршрут, дату 1 ноября–31 декабря
2025, день/месяц/год, направление и остановку. День содержит 24 часа; месяц —
дни до конца выбранного месяца; год — 12 месяцев и начинается с первого числа.
После декабря годовой сценарий повторяет средний профиль дня недели/часа;
годовая сезонность не обучена и годовой score не заявляется. Ответ `points[].basis`
отмечает конкурсный период ноября–декабря 2025 и сценарное продолжение в 2026.
Двенадцать точек и HTTP 200 проверяют доступность расчёта, но не качество
годового прогноза. В интерфейсе опубликованного прогноза год ведёт к этому
сценарию, не к `GET /forecasts`.

Опубликованный прогноз связан с неизменённым лучшим CSV. В режиме «Эксперимент
с внешними источниками» доступны четыре независимых переключателя: календарь,
погода, трафик, новости. Расчёт — среднее базовой модели и включённых отдельных
моделей; при всех выключенных работает только база. Это исследовательский
режим: он слабее опубликованного прогноза. Ручные коэффициенты 0–3 независимы
от переключателей моделей и являются сценарными допущениями. CSV сохраняет
снимок с фильтрами и происхождением расчёта.

Собраны 163 неотредактированных численных сообщения о трафике за 106 дней
января–октября 2025 из публичного [DtOperativno](https://t.me/s/DtOperativno).
Это редкие общегородские сводки, не непрерывные дорожные датчики. Новости из
того же официального канала описывают предшествующую активность публикаций о
перекрытиях/инцидентах. Четыре категории признаков не означают четыре независимых
поставщика. Сохранены даты, ссылки, численные факты и хеши; полный текст публикаций
не коммитится. Исторические признаки обрезаются до даты прогноза, однако архивная
неизменность источника и старые версии погодных данных не доказаны.

[Полный отчёт источников и ablation](../2026-09-27-external-factors/README.md):
каждый источник проверен на одинаковых трёх окнах, но устойчивого прироста от
всех четырёх нет. Ни экспериментальная смесь, ни остановочная регрессия не
заменяют incumbent. Остановочная модель не устраняет отсутствие наблюдаемых
остановок/направлений и годовой истории.

|Критерий скриншота|Результат и доказательство|Что остаётся|
|---|---|---|
|2а: четыре внешние категории, до 4|Источники, воспроизводимые признаки, все 16 комбинаций, одинаковые ablation|Полные 4 балла не обоснованы: устойчивый положительный эффект четырёх категорий не получен|
|2б: область/адаптация, до 2|10 известных маршрутов; история январь–октябрь; прогноз ноябрь–декабрь; ограничения в UI/API|Для нового маршрута нужны история, каталог GTFS и новая временная валидация; год и пространственная точность не проверены|
|2в: коэффициенты и агрегация, до 2|Коэффициенты реально меняют ответ; сохранение маршрутной суммы с неизвестной частью проверено; воспроизводимые артефакты с хешами|Оценку даёт жюри; коэффициент сам по себе не доказывает внешний эффект|
|3: архитектура/производительность, до 5|Docker, отдельные ML/API/UI слои, параметры маршрута/времени/остановки/направления, живой smoke и замеры ниже|Нагрузочный тест короткий локальный, не испытание длительной масштабируемости|
|4: полнота, до 4|День/месяц/качественный год, фильтры, график/карта/таблица, CSV; настоящие координаты GTFS|Остановка/направление оценочные; движение конкретного вагона без телеметрии не определяется|
|5: бизнес-ценность, до 2|Пики посадок и сравнение допущений для планирования выпуска/интервалов|Посадки не равны наполнению салона: без высадок и вместимости нельзя доказать снятие перегруза|

Это оценка готовности доказательств, не обещание баллов. Для внешних факторов
следующий содержательный шаг — более плотная историческая серия трафика,
доступные на дату прогноза погодные архивы и заранее датированные события;
повторить замороженную ablation на новых временных окнах. Число перебранных
моделей не заменяет независимую проверку.

## Проверки и производительность

Lead `make check`: 393 backend passed / 52 SQL skipped, 1469 ML, 98 frontend,
119 contracts; lint, types, build, OpenAPI, Compose — exit 0. SQL-проверки отдельно
выполнены при начальной интеграции: чистая миграция, 52 SQL tests, scored upgrade.
Новых миграций в этой работе нет. `npm run test:e2e -- --workers=2` на Docker UI:
52 passed. `BASE_URL=... FRONTEND_URL=... ./scripts/smoke.sh`: passed.
Живой HTTP проверил все горизонты, фильтры GTFS stop/direction, множитель 1.2
и сохранение суммы. Браузер без API-моков переключил источник, получил 12
месяцев, выгрузил CSV; ошибок JavaScript нет. Внешняя картографическая подложка
загрузилась. Отдельно все 16 комбинаций сравнивались с исходными массивами
эксперимента; отключённые ветки не входят в среднее.

Команда замера: `.venv/bin/python scripts/benchmark_forecast.py --url <endpoint>
--requests 200 --concurrency 4 --output <file.json>`; для planning добавить

Зависимости и lock-файлы не менялись. Независимые reviews остановочного
