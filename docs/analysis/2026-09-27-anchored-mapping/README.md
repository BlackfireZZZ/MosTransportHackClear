## Контракт

Кандидаты рейса ограничены маршрутом, выходом из четвёртой части GTFS trip_id,
служебной датой и часами. События разных вагонов не объединяются. Окна расширены
максимум на 15 минут; зазор между соседними рейсами делится пополам. Пересечения
остаются неоднозначными. Если первая доступная оплата отстоит от начала расписания
больше чем на 15 минут, остановка не назначается.

Используется прежний `adaptive_supports + coalesce`, frozen adaptive95 из
[сохранённого порога](detector-thresholds.json). Калибровка январь–апрель 2025;
это ретроспективная разметка, не доказательство исторической доступности признаков.
Только сильное начало с уникальной ближайшей остановкой в пределах 90 секунд,
сохраняющее эту остановку при ±15 секунд, корректирует часы этой и следующих
остановок. Уже пройденные часы не меняются; слабые совпадения сдвиг не обновляют.
Это локальная коррекция от предыдущего якоря, не общий сдвиг выхода на весь день.

Валидации внутри `[прибытие_i, прибытие_i+1)` относятся к остановке i; точное
прибытие — к новой остановке. Расчётная конечная включена, события после неё
остаются неизвестными. Равные часы разных остановок неоднозначны, кроме
обязательного первого якоря. Для ночного рейса читается контекст предыдущих
суток; в итог попадает только запрошенная дата. Исходный маршрут/час не сдвигается.

## Перенос расписания, явно одобренный пользователем

Когда у выхода нет действующего календаря, берётся ближайшая дата 2025 года
с тем же маршрутом, выходом и типом дня: рабочий / суббота / воскресенье или
праздник. При равном расстоянии выбирается прошлое. Действующий календарь
приоритетен; другой выход ради покрытия не подставляется. Отсутствие рабочего
расписания или неизвестный выход остаются неизвестными.

Даты донора могут лежать позже даты оплаты; весь feed получен поздним снимком.
Перенос — дополнительное ретроспективное предположение, не факт движения.
`ledger.csv.gz` разделяет `active_calendar` / `transferred_calendar` и основания
первого якоря / сильного начала / предыдущей остановки. В `trips.csv.gz` сохранены
дата донора и расстояние переноса. Остановочные агрегаты имеют уникальный ключ и
`label_origin`, включая смешанное происхождение, если один час содержит оба типа.

## Воспроизведение

Из dedicated worktree; все входы неизменяемы, выход должен быть новым:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python \
  -m tramflow_ml.boarding.duty_mapping --anchored --transfer-calendar \
  --source ../boarding-real-alignment/ml/artifacts/boarding-date-shards \
  --archive ../boarding-absolute-clock/ml/artifacts/clock-sources/moscow-gtfs-20260630.zip \
  --audit-manifest ../boarding-dataset/ml/artifacts/boarding-2025-reviewed/manifest.json \
  --out ml/artifacts/full-anchored-transfer-v3
.venv/bin/python scripts/rebuild_duty_mapping.py ml/artifacts/full-anchored-transfer-v3
.venv/bin/python scripts/audit_anchored_mapping.py \
  --run ml/artifacts/full-anchored-transfer-v3 \
  --baseline ../duty-mapping-full-20260927/ml/artifacts/full-duty-mapping-v1 \
  --source-ledger ../boarding-dataset/ml/artifacts/boarding-2025-reviewed/mass_ledger.csv \
  --out docs/analysis/2026-09-27-anchored-mapping/full-audit.json
```

Без `--transfer-calendar` включается v2 только по действующим календарям. Без
обоих флагов сохраняется исходный v1. Сырые события и event-level идентификаторы
не экспортируются в Git; сохранены агрегаты и воспроизводимый код. Текущий
конкурсный CSV и обслуживаемая остановочная модель этой командой не заменяются.

## Источники и ограничения

[GTFS](https://gtfs.org/documentation/schedule/reference/) определяет расписания
и расширенные часы служебных суток, но не подтверждает местоположение вагона.
[NumPy searchsorted](https://numpy.org/doc/stable/reference/generated/numpy.searchsorted.html)
задаёт политику точных границ. Суффикс выхода и первый якорь — наши гипотезы.
[Предшествующий локальный алгоритм](../2026-09-26-boarding-matching/README.md),
[отрицательная проверка общего дневного сдвига](../2026-09-27-duty-clock/README.md).
Географическая точность не измерена; действительность исторических рейсов и
ограничения движения не подтверждены. Новый датасет не является наблюдаемой
остановочной разметкой и не даёт права заявлять новый leaderboard score.
