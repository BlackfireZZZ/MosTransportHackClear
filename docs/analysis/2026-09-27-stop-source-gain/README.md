# Проверка прироста от внешних источников в остановочной модели

**Устойчивое улучшение не подтверждено. Ни один вариант не принят.**
Проверены 3 набора признаков × 4 ограничения коррекции × 3 временных окна.
У всех вариантов одинаковые актуальные восстановленные остановочные данные
anchored-v3, выборка строк, seed и бюджет обучения. Прежний конкурсный прогноз
и действующая базовая остановочная модель не изменены.

## Что именно сравнивается

- Контроль без источников: обычный день недели и час, история посадок,
  признаки остановки; без праздников, календарной сезонности и внешних данных.
- Базовая модель интерфейса: `calendar_weekday_blend`, уже использует календарь.
- Кандидат: календарный профиль и ограниченная остаточная CatBoost-коррекция
  с календарём, погодой, трафиком и мероприятиями.
- Дополнительный контроль: такая же обученная коррекция только с календарём.
  Он отделяет эффект остальных источников от эффекта изменения алгоритма.

Основная метрика — WAPE по известным остановкам (меньше лучше). Это ошибка
по **восстановленным**, а не наблюдаемым посадкам. Отдельно считаем маршрутный
балл `max(0, 1 − WAPE)` по реальным маршрутным суммам, больше лучше.
Ячейки с неизвестной остановкой исключены из основной метрики и сохранены
в дополнительной all-cell метрике. Они не должны скрывать ухудшение на карте.

## Результат

Ниже один из заранее заданных кандидатов, ограничение коррекции ±10% профиля.
Это иллюстрация компромисса, **не выбранный победитель**. Для контроля без
источников применяется та же обученная модель и то же ограничение ±10%.
Каждое окно содержит 61 день; обучение заканчивается перед его началом.

| Начало окна | WAPE без источников | WAPE базовой модели | WAPE со всеми источниками | Маршрутный балл базовая → все |
|---|---:|---:|---:|---:|
| 1 мая | 53.5029% | 52.9972% | 51.4722% | 0.863650 → 0.863631 |
| 1 июля | 53.6643% | 57.1395% | 55.7581% | 0.821189 → 0.835884 |
| 1 сентября | 50.4752% | 52.6537% | 52.1994% | 0.885934 → 0.855695 |

Относительно действующей базовой модели ошибка остановок снижается на
2,8775% / 2,4175% / 0,8628% относительно исходной ошибки. Но по сравнению с
сопоставимым вариантом без источников она меняется на −3,7955% / +3,9016% /
+3,4161%: июль и сентябрь ухудшаются. Сентябрьский маршрутный балл падает
на 0,030239, намного больше допустимых 0,002.

По сравнению с обученным календарным контролем добавление погоды, трафика и
мероприятий снижает остановочную ошибку на 1,1398% и 1,6887% в мае/июле,
но повышает на 0,4016% в сентябре. Это не доказывает пользу каждого источника
по отдельности и не даёт устойчивого выигрыша всему набору.

До обучения зафиксирован порог: уменьшение известной остановочной WAPE минимум
на 1% относительно **обоих** контролей в мае и июле, без ухудшения в сентябре;
потеря маршрутного балла не более 0,002 в каждом сравнении. Все ограничения
коррекции 0 / 2,5% / 10% / 25% провалили уже майско-июльский этап.
`selected_cap_before_diagnostic = null`. Новые настройки после отказа не подбирались.
Сентябрь ранее просматривался и не является слепой проверкой.

## Проверяемые доказательства

[Исходный план](plan.json) записан до первого обучения, SHA-256
`5ecddbb29bfa9708b54eb0e414118236c9c9bbcc2a9b418577bcc12f55112e29`.
[Все результаты](results.json) содержат 36 комбинаций, ошибки по дням,
маршрутам, месяцам и неделям горизонта, хэши прогнозов и решение по каждому
ограничению. Независимая проверка восстановила метрики из суточных ошибок
и знаменателей с расхождением менее 1e-12.

Код первого прогона и его зависимости доступны в коммите `b5391c9`.
После первого эксперимента интегрирован `4477342`, удаляющий неподтверждённый
режим источников из продукта. Для воспроизведения оставлен только автономный
офлайн-помощник `scripts/stop_source_gain_features.py`: вычисления перенесены
без изменения. Новый план повторного прогона хранится отдельно; исходный план
не переписывается. Проверка повторения: `replay-verification.json`.

Источники: погода — историческое среднее последних 28 дней, трафик — редкие
общегородские снимки за 56 дней, KudaGo — неполный ретроспективный архив,
по которому используется частота ближайших событий за прошлые 84 дня.
Нет исторических прогнозов погоды или подтверждения доступности архива KudaGo
на даты прогнозов. География и привязка остановок ретроспективны.
Восстановленные посадки не подтверждают реальную точность по остановкам.

Методология: [rolling-origin validation](https://otexts.com/fpp3/tscv.html),
[CatBoost fit](https://catboost.ai/docs/en/concepts/python-reference_catboostregressor_fit).
Внутренние обучающие окна используют только данные до своей даты прогноза;
динамические признаки не читают будущие наблюдения. Остаточная коррекция с
ограничением — проверенная здесь гипотеза команды, не гарантия из документации.

## Воспроизведение

Из dedicated worktree с закреплённым окружением (`uv sync --all-packages
--all-extras --locked`), при наличии приватных агрегированных данных:

```sh
PYTHONPATH=ml/src .venv/bin/python scripts/experiment_stop_source_gain.py \
  --source ../stop-schedule-warp-20260927/ml/artifacts/full-anchored-transfer-v3 \
  --route-export ../full-features-20260927/ml/artifacts/full-features-v2/routes \
  --weather data/weather/2025/route-weather.csv.gz \
  --posts data/external-traffic/observations.jsonl \
  --events docs/analysis/2026-09-27-stop-source-variants/event_starts.csv \
  --report /tmp/stop-source-gain-reproduction \
  --output ml/artifacts/stop-source-gain-reproduction
```

Пути также входят в план; для нового каталога создаётся новый план с теми же
параметрами. Сравнивать следует все 36 `prediction_sha256` и метрики с
`results.json`. Архив организаторов и идентификаторы пассажиров в Git не входят.
