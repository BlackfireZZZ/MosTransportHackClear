# Кандидат с переключаемыми внешними источниками (не отправлен на лидерборд)

Опубликованный режим `approved` по умолчанию сохраняет модель с публичным
результатом 0.89195 ([скриншот платформы](../../../../docs/evidence/leaderboard-2026-09-27.png))
и SHA-256 конкурсного CSV
`edc07cca26ff21dd5228f744dea79940eb81a65c3ce5368aa743e2fc2fd0f11f`.
Скриншот не показывает имя загруженного CSV; его идентичность и сетка проверяются
отдельно. Дополнительный путь POST с `source_enabled` использует четыре независимо
обученные ветки. Каждая включённая ветка получает вес 0.05, исходная модель —
оставшийся вес (0.80 при включении всех четырёх). CSV смеси содержит все 14 640
ключей организатора; его SHA-256 —
`139c0da83fcbbbbf9a5e7f13cf6f69d4b19959a60463e88ebfc4856955336757`.
Это **локальный кандидат** без наблюдаемого публичного результата.

## Хронологическое сравнение

Score равен `1 - WAPE` после одного финального округления. В каждой строке
таблицы варианты проверяются на одной и той же 61-дневной сетке
«маршрут × дата × час»; используются только метки до даты начала прогноза.
Майское окно служило для настройки первоначального опыта, ориентированного
только на score. Июльское и сентябрьское окна уже применялись в прежних
экспериментах репозитория, поэтому не являются слепой контрольной выборкой.
Веса переключаемых веток зафиксированы до этого прогона.

| Начало окна | Исходная модель | Только календарь | Только выпущенный прогноз погоды | Только трафик | Только сообщения об инцидентах | Все четыре ×0.05 |
|---|---:|---:|---:|---:|---:|---:|
| 2025-05-01 | 0.858811 | 0.847462 | 0.846747 | 0.846747 | 0.846747 | 0.857411 |
| 2025-07-01 | 0.839799 | 0.811700 | 0.831503 | 0.817844 | 0.830584 | 0.837300 |
| 2025-09-01 | 0.892071 | 0.885797 | 0.881487 | 0.886930 | 0.881082 | 0.891971 |

Отдельные ветки уступают исходной модели. Календарь с весом 0.05 немного
улучшает сентябрь (0.892227), но ухудшает май и июль; погода, трафик и
сообщения об инцидентах не дают устойчивого прироста. Смесь всех четырёх
уступает на 0.001400 / 0.002499 / 0.000100 на трёх окнах — в пределах
заданного пользователем допуска 0.003 для каждого окна. В июле маршрут 7
теряет 0.009412, а маршрут 50 прибавляет 0.001609; в сентябре маршрут 7
прибавляет 0.001152. Метрики по всем маршрутам и шестичасовым интервалам,
включая неопределённый WAPE для нулевого маршрута 5, находятся в
[манифесте артефакта](../../../../data/planning/approved-source-variants-manifest.json).
Этот локальный результат не проходит правило публикации модели с улучшенным
score. Ни `current.json`, ни `approved.json` не менялись.

Первоначальный опыт с отбором только по score выбрал `w₀=1` и нулевые веса
всех источников. Его [метрики](approved-external-evaluation.json) и
[побайтово совпадающий CSV](approved-external-candidate.csv) сохранены как
доказательство изменения цели приёмки по запросу пользователя.

## Доступность и происхождение источников

- [Архив выпущенных прогнозов погоды](../../../../data/weather/issued-2025/manifest.json)
  получен из [Open-Meteo Historical Forecast API](https://open-meteo.com/en/docs/historical-forecast-api),
  объединяющего первые часы архивных оперативных выпусков. Модель использует
  погоду с датой как минимум за два дня **до** начала каждого окна. Центр Москвы
  служит приближением для всех маршрутов; фактическая погода ноября–декабря
  2025 не используется. Сохранено 7 296 часов; SHA-256 gzip-файла —
  `04f4acd4a74f044d64b80150f5a25eb5de9ed8c6c3bd47c907e061b01f23528e`.
  Это не прогноз погоды на 61 день. Данные Open-Meteo требуют указания
  авторства по [CC BY 4.0](https://open-meteo.com/en/terms).
- [Официальные оперативные сообщения](../../../../data/external-traffic/manifest.json)
  отбираются по московскому времени публикации: сообщения с отметкой о правке
  и наблюдения на дату начала окна или позже исключаются. Ветка `traffic`
  использует прежние баллы пробок; `events` — прежние сообщения об инцидентах
  и перекрытиях. Это **заместитель оперативных новостей**, а не календарь
  городских мероприятий. Страницы загружены в 2026 году; отсутствие отметки
  о правке лишь косвенно указывает на сохранность редакции, но не доказывает
  точный текст 2025 года. SHA-256 исходного JSONL —
  `371d80c420eb25fd7132487b6d23736f407ee84a93edfc042f1be3b2096ef524`.
- Для событий KudaGo нет снимка с доказанной доступностью на дату начала окна
  2025 года, поэтому они не входят в эти ветки. Официальный календарь 2025
  опубликован 04.10.2024. Исходная модель уже учитывает день недели, месяц,
  день года и тип рабочего/праздничного дня; календарная ветка проверяет лишь
  расстояние до официальных исключений и соседство с ними.

Артефакт переключаемых источников отделён от неизменённого артефакта
`external_experiment`. Его SHA-256 —
`7be15426effaa69dd9e0207ed67c1c3b3a73bc64630778a395caa2407bd5d35c`;
хеш также записан в манифесте.

## Воспроизведение

Версии Python-пакетов: CatBoost 1.2.10, NumPy 2.5.3, pandas 3.0.6,
tramflow-ml 0.1.0. Seed — 42; CatBoost использует 400 деревьев, глубину 4,
скорость обучения 0.04 и MAE. Точная конфигурация, хеши источников, веса и
метрики по маршрутам/часам находятся в манифесте артефакта. Новых
зависимостей нет.

```sh
uv sync --all-packages --all-extras --locked
mkdir -p /tmp/tramflow-issued-2025
uv run --package tramflow-ml python -m tramflow_ml.issued_weather \
  --output /tmp/tramflow-issued-2025/hourly.csv.gz
sha256sum /tmp/tramflow-issued-2025/hourly.csv.gz
uv run --package tramflow-ml --extra boosting python -m tramflow_ml.approved_external \
  --archive /private/organizer/dataset.zip \
  --reconciliation /private/organizer/reconciliation.json \
  --weather data/weather/issued-2025/hourly.csv.gz \
  --posts data/external-traffic/observations.jsonl \
  --output-dir ml/competition_submissions/2026-09-27/approved-external-candidate \
  --artifact-dir data/planning --generated-at 2026-09-27T21:56:00+03:00
```

Сборщик отказывается заменять существующий погодный файл. Перед использованием
сравните SHA временного файла с зафиксированным источником. Архив организатора
и доказательство сверки остаются вне Git. Требуемый SHA-256 архива —
`7e34e56b93f7379cb5abe9aca8e87967cb986111b9939caead5a3fea6c296e5a`.
